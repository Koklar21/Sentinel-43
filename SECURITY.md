# Security Policy

## Reporting a Vulnerability

Please do not publish credentials, secrets, personal data, or working exploitation details for a serious vulnerability in a public issue.

Use GitHub's private vulnerability reporting for this repository when it is available. If that channel is unavailable, contact the repository owner through a private channel before publishing sensitive technical details.

Include the affected revision, affected component, practical impact, expected and observed behavior, and the smallest safe reproduction you can provide.

Do not test Sentinel-43 against systems, accounts, or networks you are not authorized to test.

## Scope

Security review should preserve Sentinel-43's human-gated authority model. Detection, telemetry, Heart, Fenrir, Watchtower, Sparta, routers, and adapters are evidence or recommendation components and must not become independent enforcement authorities.

See `REVIEWING.md` for the independent-review guide.
